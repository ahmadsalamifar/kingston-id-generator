🇬🇧 About Project

I developed this tool to generate realistic Kingston University London student ID cards. The main goal was to create a valid-looking ID that can be used for student account creation, verifications, or design mockups.

It uses advanced CSS filters (texture, gloss, blur, and rotation) to simulate a real "scanned" document look, making the output indistinguishable from a physical card scan.

🚀 Key Features

Dual Export Modes:

Clean (Fit): A high-resolution, straight PNG image of the card (perfect for digital use).

Scanned (A4): Simulates a real card placed on an A4 scanner, complete with shadows, slight rotation, and paper texture.

Hyper-Realistic Effects: I spent time tweaking the CSS to replicate the plastic texture and scan noise of a real ID card.

Fully Editable: Simply click on any text (Name, Student ID, Faculty, Dates) to edit it directly.

Instant Identity: Use the "Randomize Info" button to generate a fresh, valid-looking identity in seconds.

Photo Upload: Easily upload and crop your own photo into the card frame.

Privacy First: Everything runs 100% in your browser. No photos or data are ever uploaded to a server.

🛠️ Tech Stack

HTML5 & Tailwind CSS (For styling and realistic effects)

JavaScript (For logic and random generation)

html2canvas & jsPDF (For high-quality rendering and export)
